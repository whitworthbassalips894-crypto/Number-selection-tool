# 特码统计 · 工具2提纯与百期热度

线上主界面已按附件 `工具.html` 替换为「工具2」模型：#1 热态、#2 遗漏、#3 周期各 7 码；#1∪#2 去掉 #3 周期组与近 5 期冷却号得到「工具2专属提纯」；同时展示三组并集、热冷同中、近 100 期热度增减导航、历年命中率总表和逐期回放。原线上固定 12 码／核心 5 码与期号轮换模型不再作为主界面展示。

「线上原本的优点」全部保留：

- 一键同步最新开奖：读取仓库 `data/draws.json`（GitHub Pages 也尝试原始文件）；仓库无更新时尝试原上游及代理。只把连续、有效且不冲突的期号写入本机，发现缺口或冲突不会静默写入。
- PWA / Service Worker 离线缓存、版本化静态资源；`src/constants.js`、`index.html`、`sw.js` 三处构建号由测试校验。
- 号码按红波、蓝波、绿波显示：推荐球、三组面板、热度格号码本体、历史开奖号、锁定记录与手动输入均带波色；卡头与热度区都有波色图例，热度底色仍表示出现次数。
- 锁定本期提纯／三组／并集快照；开奖录入或同步后自动把锁定记录归档并显示命中结果。锁定记录随导出备份一起保存和导入。
- 导入／导出备份、撤销、清空、连续期号校验与 5000 期上限。导出格式为 schemaVersion 3，包含开奖记录、当前锁定及锁定历史。
- 仓库自动数据更新、语法检查与自动化测试；内置离线底库已与 `data/draws.json` 同步到 `2026-319`（1780 期，其中 1 期因重复号码不参与有效统计）。

本地数据键为 `mark6_tool2_heat_v2`；旧版浏览器缓存不会被删除。首次使用及更新需要联网；Service Worker 提供离线缓存，同步需要网络。仓库数据仍由 GitHub Actions 定时更新。

## 开发

```sh
npm ci
npm test
npm start
npm run sync
```

构建版本需同步更新 `src/constants.js`、`index.html` 与 `sw.js`。
