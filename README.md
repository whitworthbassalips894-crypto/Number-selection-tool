# 选号工具

线上页面采用提供的「选号助手」版本：支持 10–16 码选号、锁定、回放、热度分析和本地录入、备份。统计仅供参考，不保证开奖结果。

点击「一键同步最新开奖」读取仓库 `data/draws.json`（GitHub Pages 也尝试原始文件），仓库暂无更新时尝试原有上游及代理。仅连续、有效且不冲突的期次写入本机；发现缺口或冲突时不会写入。同步会核对并保存已有锁定记录。清除手动数据也会清除同步记录，请先导出备份。新版使用独立的本地存储键，旧版浏览器数据不会被删除，也不会自动导入。

首次使用及更新需要联网；Service Worker 提供离线缓存，同步需要网络。仓库数据仍由 GitHub Actions 定时更新。

## 开发

```sh
npm ci
npm test
npm start
npm run sync
```

构建版本需同步更新 `src/constants.js`、`index.html` 与 `sw.js`。
