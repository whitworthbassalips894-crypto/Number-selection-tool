# 六合彩 · 特码三组 7 码选号助手

这是一个纯前端单页 PWA 小工具（部署在 GitHub Pages 即可直接访问），基于 `Pick-3-out-of-3-Pick-4-out-of-4` 的特码框架定制：

- **只保留特码（1 中 1）模块**（已移除三中三、四中四）；
- **每期推荐 3 组 7 码（3 × 7 码）**，由三套互补特码策略独立选出，**允许跨组号码重叠**；
- **三组独立核算**：1 个号 = 1 注（默认 10 元/注、赔率 48 倍），每组 7 注，3 组共 **21 注/期**；若开出的特码落在跨组重叠号上，命中的多组同时中奖、返奖叠加；
- **历史回放双视图**：既统计 3 组合计 21 注的整体表现（含重叠多中期数），又横向对比 `#1 / #2 / #3` 三组各自的独立命中率与返奖比。

---

## 一页 4 段结构

1. **① 数据同步**：一键从仓库 `data/draws.json`（GitHub Actions 每日抓取更新）补齐本机缺失期次；支持**快速录入开奖**（点选 1–49 号码或粘贴自动识别）与批量文本 / 本机 JSON 导入兜底。
2. **② 今日推荐（特码 · 三组 7 码）**：展示当前期 3 组 × 7 码共 21 注推荐，金圈角标（`×2` / `×3`）自动标出跨组重叠重点号；支持整套复制（3 行 × 7 个两位数号码，`、` 分隔）与单组复制，支持 `?p=` 网址跨设备对齐。
3. **③ 历史回放（无未来信息）**：第 `T` 期推荐严格只使用早于 `T` 期的历史开奖；支持按范围（近 30 / 100 / 365 期、按年份、全部）与按结果（全部期次 / 只看中奖 / 只看重叠多中）筛选。
4. **④ 设置与缓存维护**：自定义单注本金与特码赔率（即时重算投入、返奖与期望回报率），一键检查更新或修复 Service Worker 缓存。

## 快速录入开奖（点选 1–49）

「数据同步」里新增了**快速录入开奖**，把原来要手打一整行开奖号码的方式改成点选：

- **点选录入**：1–49 号码按波色排成 7×7 网格，依次点 7 个号码即可。前 6 个是**正码**，第 7 个自动成为**特码**（金圈 +「特」角标）；再点一次已选号码即可取消，选满 7 个后需先取消一个才能改选。
- **粘贴自动识别**：在输入框里粘贴 `02 08 09 13 14 31 + 45` 这类号码，会自动识别 1–49 号码并填好网格；日期、期号、生肖、「开奖号码 / 特码」等标签会被忽略。有 `+` 时优先把 `+` 后的号码当特码；没有 `+` 时第 7 个号码为特码。**6 个正码自动按从小到大排列**，特码不参与排序。
- **期号自动对齐**：期号固定取底库最新一期的下一期（按工具内置日历，跨年自动从 001 开始），不需要手填。
- **保存即生效**：保存后写入本机开奖并立即刷新推荐与回放；若该期已存在会提示是否覆盖。批量补历史仍可用下方「批量粘贴导入 / 本机开奖」。

## 三套特码 7 码策略说明

每套策略都只在目标期之前的历史开奖上打分，并通过形态均衡求解器保证单组 7 码不扎堆单区、单波色或单尾数：

| 组别 | 策略名称 | 核心选号逻辑 |
| --- | --- | --- |
| **#1** | 🔥 **热态顺势** | 聚焦近 12/30 期特码高频活跃号 + 上期正码落特码（重号传导）+ 热尾/热区顺势，兼顾特码个人间隔回补窗口。 |
| **#2** | 🎯 **遗漏回补** | 聚焦特码个人历史间隔分位偏高、长期未出特码但近期在平码露面预热的蓄势号码，捕捉冷特码与冷尾回补。 |
| **#3** | ⚖️ **周期均衡** | 基于近 80 期特码中周期密度 + 特码三区/波色一阶马尔可夫转移权重，严格约束三区 `2-2-3`、三波 `2-2-3`、奇偶/大小 `3:4` 或 `4:3` 且 7 码尾数互不相同。 |

- **跨组重叠规则**：三组独立选优，不强制互斥；同时被 2 组或 3 组选中的号码会以金圈 + `×2` / `×3` 角标高亮。
- **复制格式**：纯号码输出，组内用顿号 `、` 分隔，组间换行，不附带任何文字标签。

## 数学口径速查

- 单注命中概率：`1 / 49 ≈ 2.0408%`（理论公平赔率 `49` 倍，48 倍下期望回报率 `48 / 49 ≈ 97.96%`）。
- 单组 7 码命中概率：`7 / 49 = 1 / 7 ≈ 14.2857%`。
- 三组 21 注场均期望命中注数：`21 / 49 ≈ 0.4286 注/期`（不受跨组是否重叠影响；重叠影响的是方差与单期多中概率：设三组去重后覆盖 `K` 个不同号码，则当期至少中 1 注的概率为 `K / 49`）。

## 理性声明

六合彩每期开奖相互独立，任何历史统计与选号策略均无法改变客观命中概率（单注 `1/49`）与盘口期望回报率。本工具仅作历史数据整理与娱乐参考，请理性对待。
