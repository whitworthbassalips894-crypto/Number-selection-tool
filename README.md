# 选号工具

线上页面采用提供的「选号助手」局部修改版：固定 12 码（热势、遗漏、周期各 4 个名额），从 12 码中选出核心 5 码，并支持锁定、历史回放、热度分析、本地录入与备份。三路分配顺序按**目标期期号 ÷ 3 的余数**轮换：余 1 为「热势 → 遗漏 → 周期」，余 2 为「遗漏 → 周期 → 热势」，余 0 为「周期 → 热势 → 遗漏」；后路跳过前路已选号码，继续按自身排名补足 4 个。共鸣标签、12 码互不重复以及 01–12、13–24、25–36、37–49 各 2–4 个的区间约束保持不变，卡头会显示当期实际顺序。

页面不再展示「选号与补位规则」说明；所有展现的号码按红波、蓝波、绿波显示，推荐卡头与热度区都有波色图例，热度格中的号码本体也用波色标注，底色仍表示出现次数。信号面板改用非波色系的琥珀、紫、石板灰边框，避免与波色混淆；一键同步按钮做了浅主色强调。

点击「一键同步最新开奖」读取仓库 `data/draws.json`（GitHub Pages 也尝试原始文件），仓库暂无更新时尝试原有上游及代理。仅连续、有效且不冲突的期次写入本机；发现缺口或冲突时不会写入。同步会核对并保存已有锁定记录。清除手动数据也会清除同步记录，请先导出备份。新版使用独立的本地存储键，旧版浏览器数据不会被删除，也不会自动导入。

首次使用及更新需要联网；Service Worker 提供离线缓存，同步需要网络。仓库数据仍由 GitHub Actions 定时更新。

## 开发

```sh
npm ci
npm test
npm start
npm run sync
```

构建版本需同步更新 `src/constants.js`、`index.html` 与 `sw.js`。
