# 特码智能选号助手（PWA 单页版）

轻量、浅色、单列的选号面板。首页自上而下只有 5 个模块：顶部开奖栏 → 近 30 期策略温度计 → 下期智能主推 → 近 100 期热度分布 → 近 10 期命中简表（完整历史在弹窗里）。

## 算法（严格保留原逻辑）

选号内核完全沿用原版「工具2」，没有任何动态调权或改写：

- `#1 热态`、`#2 遗漏`、`#3 周期` 三组各 7 码，由原版加权评分 + `selectBalancedSeven` 做区间／波色／单双／大小／尾数均衡选出。
- `提纯主推` = `#1 ∪ #2` 去掉 `#3 周期组` 与近 5 期已开特码（冷却池）。
- 主推卡片上 `[ 5码 ] [ 7码 ] [ 10码 ] [ 12码 ]` 是按原版三组分数排序后从高到低直接截取前 N 码（`rankCandidatesFromPlan`），不参与任何评分修改。
- `[ 18码 ]` 档位取 `#1∪#2∪#3` 去重后的全部并集号码（历史平均 18.09 码，范围 12~21 码），同样不改动任何评分。
- 近 30 期策略温度计是纯看板，只统计历史命中率，不影响选号结果。

## 首页 5 个模块

1. 顶部栏：最新期号、上期开奖（红／蓝／绿波球，特码高亮）、`一键同步`、数据管理入口。
2. 近 30 期策略温度计：用进度条展示 `#1 / #2 / #3` 近 30 期命中数与命中率，并标注 7 码随机基线 ≈14.3%（30 期样本波动约 ±12pp），避免把随机起伏误读成趋势。
3. 下期智能主推：参考信号 + 当前连错期数、5 档码数一键切换、波色球与简短标签、`一键复制推荐号码`（纯 ASCII 逗号，如 `04,06,12,...`）、`锁定本期`、以及「本档构成（热态/遗漏个数）」提示；底部默认折叠的 `选号依据`（默认折叠，展开后先看三组摘要、「展开完整表」再看逐号明细，含 `#1 / #2 / #3 / 冷却池`）。
4. 近 100 期热度分布：7×7 网格展示 49 个号码出现次数，标记高频热号与 0 次冷号，不再有期号导航条。
5. 近 10 期命中简表：默认只列最近 10 期，`查看全部` 打开弹窗查看完整历史（1780 期有效数据），弹窗内含年度命中率总表、年份切换、期号搜索、仅看命中、分页与展开全部。

## 保留的原有能力

- 一键同步最新开奖：读取仓库 `data/draws.json`（GitHub Pages 也尝试原始文件）；仓库无更新时尝试原上游及代理。只把连续、有效且不冲突的期号写入本机，发现缺口或冲突不会静默写入。
- 内置离线底库（`index.html` 内 `COMPRESSED_DATA`，与 `data/draws.json` 一致，同步至 `2026-320`，共 1781 期，其中 1 期因重复号码不参与有效统计）。
- PWA / Service Worker 离线缓存、版本化静态资源；`src/constants.js`、`index.html`、`sw.js` 三处构建号由测试校验。
- 号码按红波、蓝波、绿波显示：开奖球、主推球、三组面板、热度格、历史开奖号、锁定记录与手动输入均带波色。
- 锁定本期快照（含当前码数与号码）并存在本机；开奖录入或同步后自动归档并显示命中结果，随导出备份一起保存／导入。
- 导入／导出备份、撤销、清空、连续期号校验与 5000 期上限。导出格式为 `schemaVersion 3`。
- 响应式：桌面居中最大宽度 880px；手机端按钮通栏、球体与 7×7 网格不溢出。

本地数据键为 `mark6_tool2_heat_v2`；旧版浏览器缓存不会被删除。首次使用及更新需要联网；Service Worker 提供离线缓存，同步需要网络。仓库数据仍由 GitHub Actions 定时更新。

## 每日摇号模拟器

首页可进入 `simulator.html`，该页面基于附件的 6+1 模拟器，使用独立的本地存储，不影响选号助手数据。每天按设备本地日期生成一次随机号码；清除浏览器数据或更换设备会失去本机限制和记录，请定期导出备份。原附件若通过本地文件打开，与网站的浏览器存储可能不同；请先在原页面导出备份，再在新页面导入。历史回放为事后生成样例，不代表事前预测。

选择已有模拟记录的期号后，可点击「从开奖底库填入本期」读取仓库 `data/draws.json`，校验期号、日期和号码后填入表单；请核对并手动保存。不会覆盖已保存的结果，底库更新可能延迟，离线或直接打开 HTML 时也可手动录入。随机模拟不提高中奖概率，也不能保证模拟发生在开奖前。

### 开奖数据与部署

模拟器打开时读取同站点的 `data/draws.json`；同站点请求失败时尝试指定 GitHub 仓库 main 分支的原始 JSON。页面显示来源、最新有效期和异常条数，数据是否及时取决于底库更新及缓存。历史回放使用最近 10 条有效底库记录作为开奖结果，模拟号为事后确定性生成，不能作为预测或实测成绩。数据不可用时显示附件内置的旧回放样例并明确标注，不会把虚构数据当作开奖结果。每日模拟记录与回放分开，历史表可直接选择本机记录进行录入。

使用 GitHub Pages 时将仓库部署为静态网站，访问首页进入模拟器，或直接访问 `simulator.html`；部署与仓库自动更新需要在 GitHub 中配置，本项目不需要后端。
