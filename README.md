# 特码 · 双方案选号助手

纯前端单页 PWA，可部署在 GitHub Pages。首页同时展示方案 A「双工具共振共同号」和方案 B「工具 1 热冷精选」，金圈标出两个方案的重叠号。每号 1 注，开奖时只核对特码。方案 A 可选择包含或排除工具 1 的 🎲 随机撞号，推荐看板与历史回放的开关同步。

- **当期推荐**：支持期号切换、`?p=NEXT` / 历史期号分享，以及复制当前 A、B 两套号码。
- **数据同步与录入**：从 `data/draws.json` 同步缺失期次；支持快速粘贴 6 正码 + 1 特码、批量录入及本地数据导入导出。录入仅保存在本机。
- **历史回放**：可切换方案 A、B；分年统计与总计展示期数、注数、命中次数、单注命中率、净收益、ROI、最大回撤和最长连黑。逐期明细可向下滚动查看全部记录，点击展开当期推荐号码；该明细不展示金额。
- **设置与缓存维护**：自定义单注本金（默认 10 元）和特码赔率（默认 48 倍），即时更新分年统计；支持修复 Service Worker 缓存。

## 算法与统计口径

工具 2 的三组 7 码引擎保持不变。`src/tool1/` 原样保留工具 1 仓库提交 `bb07a2cc47f326424957c9fe35a10c215569ac1b` 的引擎及其依赖；适配层只调用 `mode: 'special', randomSalt: 0`。方案 A 是工具 1 的 12 码与工具 2 三组去重并集的交集；方案 B 是工具 1 分类中的 3 个热号及 2 个冷号。

全量回放逐期重新选号，只使用严格早于该期的数据，并排除体检不合格的开奖（最早期历史不足时保留原引擎兜底行为）。每年从零累计，最大回撤为期末累计净收益距此前最高值（含初始零）的最大下降；总计跨年连续计算。连黑为连续未命中的期数。ROI = 净收益 / 总本金，单注命中率 = 命中注数 / 总注数。

## 本地开发与测试

```bash
npm install
npm test
npm start
```

更新开奖底库使用 `npm run sync`；自动每日同步由 `.github/workflows/sync-draws.yml` 执行。浏览器同步与手动录入不会修改仓库中的内置底库。

## 理性声明

每期开奖相互独立，任何历史统计与选号策略均无法改变单注理论命中概率（1/49）。历史回测不代表未来表现，本工具仅作数据整理与娱乐参考，请理性对待。
